## Installation

### Prerequisites
- Git
- Python 3.11+
- Any required libraries specified in individual assignment files

### Setup
1. Clone or download this repository.
2. Open the assignment folder you want to work on.
3. Install any dependencies mentioned in the assignment documentation.
4. Run the files using your preferred Python environment.

## Usage

1. Navigate to the relevant assignment directory.
2. Read the assignment instructions and source code.
3. Execute the program or notebook according to the assignment requirements.
4. Review the output and modify the code for learning and experimentation.
